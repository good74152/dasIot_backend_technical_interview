# dasIot_backend_technical_interview

DasIoT Backend Technical Interview 的解答。

## 使用技術

- TypeScript
- Node.js 20+
- Vitest（單元測試）
- tsx（直接執行 TypeScript）

## 專案結構

```
.
├── src/     # 解答程式碼
├── test/    # 單元測試
├── package.json
└── tsconfig.json
```

## Getting Started

### Install

```bash
npm install
```

### Run

```bash
npm run dev
```

### Run Tests

```bash
npm test
```

### Type Check

```bash
npm run typecheck
```
